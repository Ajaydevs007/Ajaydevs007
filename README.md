## 🧑‍💻 About Me

BCA graduate with 16 months of web development 
experience (MERN Stack + React) who made a 
deliberate move into cybersecurity.

After building full-stack applications and working 
with APIs, authentication flows, and web architecture, 
I kept asking one question — how do attackers break 
what developers build?

That question led me to complete the **Offenso 
Certified Security Professional (OCSP)** program 
at Offenso Academy, Kozhikode — a hands-on offensive 
security course covering:

- Network & machine penetration testing
- Web application attacks (OWASP Top 10)
- Active Directory exploitation & Kerberos attacks
- Linux fundamentals & system security
- API security vulnerabilities

I now combine that offensive knowledge with defensive 
SOC skills — because the best analysts think like 
attackers.
